How this site works

A second page, to show how pages share their header and how text is set. It lives in src/about/index.html, so its address is /about/.

Only files

Nothing runs on the server for this site. At each deploy the panel downloads the repository, runs npm run build, and points nginx at the dist/ folder the build wrote. A visit is nginx sending a file.

That makes the site fast and hard to break, and it sets its limits: no database, no form that saves something, no page that depends on who is reading it. When you need one of those, start from the app template.

Who can open it

The panel decides, with the site's access: everyone, anyone with an account, or one or more groups. Behind the sign-in, nginx asks for the account before it sends any file, and the header shows Sign out.

The pages themselves never know who is signed in, and they hold no secret. Every file of the site reaches the browser of whoever may open it, so write nothing in it that those people should not read.
