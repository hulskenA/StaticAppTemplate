A starting point in the house style for a site made of files: pages, parts shared between them, and the charter's type, cards and buttons. Replace these pages with your own.

See how it works

What is here

description

Pages

Each .html file in src/ is a page. A folder with an index.html gets a short address, like /about/.

dashboard_customize

Shared parts

The header, the footer and the fonts are written once, in src/_parts/, and every page includes them.

palette

The charter

Colours, type, cards and buttons come from src/ds/, the same two files the panel and the apps use.

fact_check

Checked before it ships

npm test builds the site and follows every link, so a missing page or picture is caught on your PC.

Working on it

npm run dev
Opens the site on your PC. The page reloads each time you save.
npm test
Builds the site and checks its pages and links. Run it before each push.
git push
Then press Deploy on the site's page in the panel. The previous build stays one click away.
